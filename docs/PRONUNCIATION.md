# TTS 발음 변환 메모 (대본 담당 공유용)

`pipeline/src/pipeline/utils/pronounce.py`는 내레이션(narration)을 ElevenLabs에 보내기 직전에 숫자·영문·기호를 읽는 그대로의 한글로 바꾼다. 자막(subtitle_text)은 바꾸지 않는다.

- 테스트: `cd pipeline && uv run --with pytest pytest -q tests/test_pronounce.py` (예시 전체, API 호출 없음)
- 변환 결과 확인: `python -m pipeline.utils.pronounce`, 또는 코드에서 `analyze(문장)` 사용. 애매해서 바꾸지 않은 곳은 `notes`로 나온다

## 1. 발음 규칙 요약

| 분류 | 예 |
| --- | --- |
| 숫자 표기 | 1,000원 → 천 원 · 64.0% → 육십사 퍼센트 · 3%p → 삼 퍼센트포인트 · 1만 2천 → 만 이천 · 1억 → 일억 · 09시 → 아홉 시 |
| 날짜·시각 | 2026.11.14(금) → 이천이십육 년 십일월 십사일 금요일 · '26년 → 이십육 년 · 15:30 → 열다섯 시 삼십 분 |
| 비율·분수 | 30:1 → 삼십 대 일 · 1/3 → 삼분의 일 |
| 전화번호 | 1588-1234 → 일오팔팔에 일이삼사 · 02-123-4567 → 공이에 일이삼에 사오육칠 (0은 공) |
| 고유어 단위 | 2달 → 두 달 · 2배 → 두 배 · 15시 → 열다섯 시 · 3시간 → 세 시간 · 1번째 → 첫 번째 · 2곳 → 두 곳 · 3차례 → 세 차례 |
| 고유어 범위 | 살·번째 99까지, 시 24까지, 그 밖 20까지 고유어. 넘으면 한자어 (60문제 → 육십 문제, 150명 → 백오십 명) |
| 한자어 단위 | 분·초·월·일·년·주·개월·원·점·회·급·층·학점·세·위·차·과목 등 (5과목 → 오 과목) |
| 월 예외 | 6월 → 유월 · 10월 → 시월 |
| 범위(~) | 1일~16일 → 일일부터 십육일까지 · 3~4주 → 삼사 주 · 2~3개 → 두세 개 · 3~4개 → 서너 개 · 30만~50만 원 → 삼십만에서 오십만 원 · 70~80% → 칠십에서 팔십 퍼센트 |
| '번' | 뒤에 오는 말로 판단 (한자어 목록을 먼저, 긴 낱말부터): 3번 문제 → 삼 번 문제 · 3번 응시 → 세 번 응시 · 판단할 수 없으면 그대로 |
| '단계' | 기본은 순서(한자어): 1단계 필기, 2단계 실기 → 일 단계 필기, 이 단계 실기. 개수를 뜻하는 말이 뒤에 오면 고유어: 3단계로 나누어/를 거쳐/에 걸쳐/만에/씩 → 세 단계 |
| 단위 기호 | 5km → 오 킬로미터 · 4.5m → 사 점 오 미터 · 16GB → 십육 기가바이트 · -5℃ → 영하 오 도 · $100 → 백 달러 |
| 영문 | 사전: TOEIC 토익 · OPIc 오픽 · PSAT 피셋 · CAD 캐드 · HACCP 해썹 · Q&A 큐앤에이 · 1+1 원플러스원 / 대문자 약어: CBT → 씨비티 · A형 → 에이형 / 글자+숫자: 5G 파이브지 · A4 에이포 · B2B 비투비 / 그 밖의 영어 단어는 그대로 |
| 기호 | Ⅱ → 이 · → ※ ★ 같은 장식 기호는 지움 |

숫자와 단위 사이는 띄운다(두 달, 열다섯 시, 삼사 주, 오 킬로미터, 십육 점 칠 퍼센트). 단, **날짜의 월·일은 붙인다**(구월 일일, 시월 십일, 이천이십육 년 구월). 띄우면 TTS가 끊어 읽을 수 있고 '일 일'이 어색하기 때문이다. 년은 띄운다. 조사는 붙인다(1과 2 → 일과 이). GPT가 이미 한글로 쓴 표현(스무 문제)은 숫자가 아니므로 건드리지 않는다.

## 2. 적용 순서

앞 단계에서 한글로 바뀐 부분은 뒤 단계가 다시 건드리지 않는다.

1. 사전 (기호·숫자가 섞인 단어를 먼저: Q&A, 1+1, 3.1절, 6.25 전쟁)
2. 특수 표기 (D-30, No.1, 1st, x2)
3. 전화번호 (날짜보다 먼저)
4. 날짜·분수 (소수보다 먼저)
5. 시각·비율
6. 화폐
7. 범위(~)
8. 숫자+단위 (단위 기호 → 한글 단위 → '번')
9. 남은 숫자
10. 영문 (글자+숫자 → 대문자 약어)
11. 기호
12. 공백 정리

**자막 싱크 보호**: `s07_subtitle.py`는 자막과 읽는 문장에서 '뒤에 공백이 오는(또는 문장 끝의) 쉼표·마침표·물음표·느낌표' 개수가 같아야 정밀 싱크를 쓴다. 그래서 변환은 이 문장부호를 만들거나 없애지 않는다. 띄어 쓴 날짜(2026. 11. 14.)는 점을 남기고, 문장부호 바로 뒤에 붙은 장식 기호는 지우지 않는다. 개수가 달라지면 경고 로그를 남긴다.

## 3. 알려진 한계

- **'번'**: "1년에 2번"처럼 뒤에 판단할 말이 없으면 숫자를 그대로 둔다. 대본에서 횟수는 "두 번"처럼 한글로 쓰는 게 안전하다.
- **여러 단위가 묶인 범위**: "9월 1일~10월 16일", "2026년 9월~2027년 3월", "9시 30분~18시"는 '부터 ~까지'로 읽는다. 양쪽 형식이 다른 범위("9월~2027년 3월")는 '에서'로만 이어 읽는다 (구월에서 이천이십칠 년 삼월).
- **'단계'**: 뒤에 정해 둔 말(로 나누·를 거쳐·에 걸쳐·만에 등)이 없으면 순서로 보고 한자어로 읽는다. "3단계로 진행"처럼 개수인데 목록에 없는 말이 오면 "삼 단계"가 된다. 개수라면 "세 단계"처럼 한글로 쓰는 게 안전하다.
- **추정 규칙**: 시각과 비율(1:10), 날짜와 분수(1/12)는 형식과 앞뒤 말로 추정한다. 애매한 날짜는 날짜로 읽고 `notes`에 남긴다.
- **GPT가 한글로 잘못 쓴 숫자**: "십월"처럼 이미 한글로 쓴 것은 숫자가 아니라서 코드가 고칠 수 없다.

## 4. 제안: 숫자는 원래 표기로 쓰고, 발음은 코드가 맡기

지금은 `script.md`가 GPT에게 내레이션의 숫자를 한글로 풀어 쓰게 한다. 그런데 대본 20개를 확인해 보니 숫자가 그대로 남은 장면이 많았고(대본 단계의 숫자 검사로 재시도해도 남음), GPT가 한글로 잘못 쓴 것은 코드가 잡을 수 없다. 영문 약어는 이미 "원래 표기로 쓰고 코드가 바꾸는" 방식이므로 숫자도 같은 방식으로 맞추자는 제안이다.

| | 지금 (GPT가 한글로 씀) | 제안 (GPT는 원래 표기, 코드가 변환) |
| --- | --- | --- |
| 일관성 | 같은 숫자도 대본마다 다르게 쓸 수 있음 | 규칙 하나로 항상 같게 읽음 |
| 오류 수정 | 잘못 쓴 한글은 찾기 어렵고, 고치려면 대본을 다시 만들어야 함 | 규칙만 고치면 모든 대본에 적용, 테스트로 확인 가능 |
| 문맥 판단 | GPT가 문맥으로 고유어/한자어를 고름 (3번 응시 → 세 번) | 규칙으로 못 정하는 경우가 남음 ('번' 등) |
| 대본 단계 | 숫자 검사 때문에 재시도와 비용이 생김 | 숫자 검사가 필요 없어 재시도가 줄어듦 |
| 자막 | narration과 subtitle_text를 따로 써서 둘이 어긋날 수 있음 | 둘이 거의 같아짐 (나중에 하나로 합칠 수도 있음) |
| 관리 | 프롬프트 관리 | 발음 규칙·사전 관리, 애매한 경우의 기준 정하기 |

**절충안**: 숫자는 원래 표기로 쓰게 하되, 횟수를 뜻하는 '번'처럼 문맥이 필요한 표현은 "세 번"처럼 한글로 써도 된다는 예외를 둔다.

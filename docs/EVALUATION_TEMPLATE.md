## 평가 기준

| 항목 | 확인 방법 | 근거 |
| --- | --- | --- |
| 대본 정확성 | 원문과 장면별 자막 문장을 대조해 핵심 내용 누락, 원문에 없는 주장, 수치·조건·적용 범위의 변경을 기록한다. | 사람 판단 + CSV `fact_issues`, `points_covered` |
| 길이와 구조 | 최종 MP4가 30~60초인지, 도입·설명·마무리가 이어지는지 확인한다. | CSV `video_sec`, `length_ok` + 사람 판단 |
| 대본 형식 | 장면 수, 장면별 글자 수, 읽는 문장 속 숫자, 첫 장면 주제 정의 규칙을 지켰는지 본다. | CSV `format_violations` |
| 장면 적합성 | 완성된 그림이 해당 내레이션의 핵심을 시각적으로 전달하는지 확인한다. | 사람 판단 |
| 화풍 일관성 | 장면 간 흰 배경, 검은 선, 여백, 선 굵기를 비교하고 의도하지 않은 글자와 숫자를 기록한다. | 사람 판단 + CSV `image_text_scenes` |
| 드로잉과 자막 | 그림이 순서대로 그려지는지, 자막이 말과 함께 넘어가는지, 의미 단위가 어색하게 끊기는 곳이 있는지 기록한다. | 사람 판단 + CSV `subtitle_timed`, `subtitle_drift_max`, `subtitle_in_video`, `av_diff_sec` |
| 발음 | 영문 약어·숫자·단위를 잘못 읽은 곳을 기록한다. | 사람 판단 |
| 실행 결과 | URL부터 MP4까지 완료 여부, 처리 시간, 실패 단계와 재실행 여부, 비용을 기록한다. | CSV `gen_sec`, `runs`, `cost_usd` |

자막 전환 시점은 TTS가 돌려준 글자별 발화 시각으로 맞춥니다(`subtitle_timed`가 전체 장면 수와 같을 때). 시각 정보가 없는 장면은 글자 수 비율로 나눕니다.
